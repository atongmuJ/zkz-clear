张开嘴清理 · 绿色版（解压即用）
========================================

【怎么用】
  1. 右键下载的 zip →「全部解压缩」到一个文件夹
  2. 双击「张开嘴清理.exe」即可运行，无需安装
  3. 点白色按钮「扫描电脑」，看完列表再点「清理选中项」

【绿色版特点】
  - 不写注册表、不装服务、不常驻后台
  - 配置只保存在本机的应用数据目录
  - 想卸载：直接删除整个文件夹即可，无残留
  - 可以整个文件夹拷到 U 盘，插到别的电脑也能用

【和系统里装了「安装版」冲突吗？】
  不冲突。绿色版和安装版各自独立，数据互不影响。
  两者不用同时装，按需选一个就行。

【要求】
  - Windows 10 1803+ / Windows 11，64 位
  - 不需要 Node.js、不需要 Rust、不需要 Visual Studio
  - 首次运行若缺少 WebView2，程序会自动下载安装组件

【常见提示】
  - 首次双击出现蓝色「Windows 已保护你的电脑」：
    点「更多信息」→「仍要运行」（程序未做代码签名）。
  - C 盘清理里的休眠文件、系统还原点、Windows.old 等需要管理员权限：
    右键「张开嘴清理.exe」→「以管理员身份运行」再用这些功能。
  - 清理只碰缓存子项，不动文档/照片/桌面文件；
    不放心可以先点扫描看列表，再决定清不清。
